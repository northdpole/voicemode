# poly-stt adapter

PolyAI RSN-1 speech-to-text for VoiceMode, with local Whisper as the fallback.

```bash
voicemode adapter install https://github.com/northdpole/voicemode.git --path adapters/poly-stt
```

Audio leaves your machine while this adapter is on. `voicemode adapter off poly-stt` undoes it.
